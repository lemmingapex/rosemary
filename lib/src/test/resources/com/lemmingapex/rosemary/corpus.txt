# Datetimes as real programs, protocols and people write them, and how Rosemary should read them.
# CorpusTest parses each one with the default settings, with today being 2024-06-15 (UTC).
#
# Each line is:   input | expected [| date order]
#   input       the string, with \n for a newline, \t for a tab and \\ for a backslash
#   expected    the OffsetDateTime, in ISO 8601, or "error" if the string should be rejected
#   date order  optional, e.g. DD_MM_YY; MM_DD_YY by default
#
# Most examples are 2024-03-05 19:02:13 in Denver (-07:00), which is 2024-03-06T02:02:13Z.
# When a source has a well-known example, like the RFCs, that example is used instead.
